# RaspHarmony
Sistema Embarcado Reprodutor de arquivos WAV e Sintetizador Musical Simples - Projeto da disciplina EA801 FEEC Unicamp\
O projeto é dividido em duas etapas, uma realizada na protoboard e outra na PCB, mudando alguns periféricos e configurações de pinos.\
Em ambas as versões programamos utilizando micropython.\
Na versão protoboard utilizamos a placa Raspberry Pi Pico 2, já na versão PCB utilizamos a Pi Pico.\

# Especificações 
Todas as músicas estão no formato WAV com 16 bits e taxa de amostragem (Sample Rate) padrão do sistema de 44.1kHz, considerando que o ser humano escuta até 20kHz.
